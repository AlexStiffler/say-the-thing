# Skip Hello

A friendly, interactive guide to better async chat. The page encourages people to include their question in the first message, so conversations can move forward without unnecessary waiting.

## Run it

Open `index.html` in a modern browser. The page loads Tailwind CSS from its CDN, so an internet connection is needed for styling.

## Features

- Teams-inspired dark theme with layered, 3D-style chat cards
- Smooth-scroll call to action
- Playful Yes/No interaction
- Upward confetti animation when Yes is clicked, with reduced-motion support

## Built with

HTML, Tailwind CSS via CDN, and vanilla JavaScript. No build step or custom CSS is required.
